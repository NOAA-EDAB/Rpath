# Extract node/group data from an Rsim run

Extracts group/node specific information from a scenario run using
[`rsim.run()`](https://noaa-edab.github.io/Rpath/reference/rsim.run.md)

## Usage

``` r
extract.node(Rsim.output, group)
```

## Arguments

- Rsim.output:

  Object generated by
  [`rsim.run()`](https://noaa-edab.github.io/Rpath/reference/rsim.run.md).

- group:

  Name of the node/group for which you want to extract data. Valid
  values are found in the \`Group\` field of the object created from
  running
  [`rpath()`](https://noaa-edab.github.io/Rpath/reference/rpath.md)

## Value

Returns a list object with monthly node specific data

- Biomass:

  Vector of monthly Biomass values

- AnnualBiomass:

  Vector of annual Biomass

- TotalCatch:

  Vector of monthly Catch values

- AnnualTotalCatch:

  Vector of annual Catch values

- Landings:

  Dataframe (n x l) of monthly Landings. (Each column is a fishery that
  Lands the \`group\`)

- Discards:

  Dataframe (n x d) of monthly Discards (Each column is a fishery that
  Discards the \`group\`)

## Examples

``` r
# Read in Rpath parameter file and balance model
Rpath <- rpath(Ecosense.EBS)
# Create a 50 yr Rpath scenario
Rsim.scenario <- rsim.scenario(Rpath, Ecosense.EBS, years = 1:50)
# Run a scenario
Rsim.output <- rsim.run(Rsim.scenario, method = "RK4", years = 1:50)
# Extracts group (node) specific data from the simulation run
group <- extract.node(Rsim.output,Rpath$Group['Squids'])

```
