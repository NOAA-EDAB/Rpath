# Rpath: A package implementing mass balance algorithms designed to work with fisheries data sources.

The Rpath package provides two categories of important functions: rpath
and rsim.

## Rpath functions

The Rpath functions generate the balanced snap shot of energy flow
through the system. This is done by solving a series of linear equations
for unknown biomass or ecotrophic efficiency.
