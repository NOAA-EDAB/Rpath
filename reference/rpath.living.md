# List of Rpath living groups

List of living groups from Rpath object. Living groups are those species
groups with type \< 2.

## Usage

``` r
rpath.living(Rpath)
```

## Arguments

- Rpath:

  Balanced Rpath model generated by
  [`rpath()`](https://noaa-edab.github.io/Rpath/reference/rpath.md)

## Value

Returns a string vector containing the names of Rpath functional groups
that are living.

## Examples

``` r
# Build the balanced Rpath model and parameter file by calling `rpath`
Rpath <- rpath(Ecosense.EBS)
# Run the rpath.living command
livingGroups = rpath.living(Rpath)
# Print out the first few living group names
head(livingGroups)
#> [1] "Toothed whales"      "Gray whales"         "Other baleen"       
#> [4] "Bowhead whales"      "Other pinnipeds"     "Walrus/bearded seal"
```
