# Specify a dynamic simulation scenario

Uses a static `Rpath` model and creates a scenario consisting of 5 list
objects: `params` generated by
[`rsim.params()`](https://noaa-edab.github.io/Rpath/reference/rsim.params.md),
`start_state` generated by
[`rsim.state()`](https://noaa-edab.github.io/Rpath/reference/rsim.state.md),
`forcing` generated by
[`rsim.forcing()`](https://noaa-edab.github.io/Rpath/reference/rsim.forcing.md),
`fishing` generated by
[`rsim.fishing()`](https://noaa-edab.github.io/Rpath/reference/rsim.fishing.md),
and '`stanzas` generated by
[`rsim.stanzas()`](https://noaa-edab.github.io/Rpath/reference/rsim.stanzas.md).

## Usage

``` r
rsim.scenario(Rpath, Rpath.params, years = 1:100)
```

## Arguments

- Rpath:

  R object containing a static `Rpath` model.

- Rpath.params:

  R object containing the parameters needed to create a `Rpath` model.
  This is generated either by the
  [`create.rpath.params()`](https://noaa-edab.github.io/Rpath/reference/create.rpath.params.md)
  or
  [`read.rpath.params()`](https://noaa-edab.github.io/Rpath/reference/read.rpath.params.md)
  functions.

- years:

  A vector of each year of the simulation.

## Value

Returns an `Rsim.scenario` object that can be supplied to the
[`rsim.run()`](https://noaa-edab.github.io/Rpath/reference/rsim.run.md)
function. `Rsim.scenario` is a list of 5 objects:

- `params`, list of 39 dynamic parameters and vectors derived from an
  `Rpath` model, see output of
  [`rsim.params()`](https://noaa-edab.github.io/Rpath/reference/rsim.params.md)

- `start_state`, list of 9 initial value vectors for biomass and size
  structured stanza groups, see output of
  [`rsim.state()`](https://noaa-edab.github.io/Rpath/reference/rsim.state.md)
  and
  [`rsim.stanzas()`](https://noaa-edab.github.io/Rpath/reference/rsim.stanzas.md)

- `forcing`, list of 7 matrices for time series forcing of biological
  attributes, see output of
  [`rsim.forcing()`](https://noaa-edab.github.io/Rpath/reference/rsim.forcing.md)

- `fishing`, list of 3 matrices for time series forcing of fishing
  attributes, see output of
  [`rsim.fishing()`](https://noaa-edab.github.io/Rpath/reference/rsim.fishing.md)

- `stanzas`, list of 21 parameters and vectors for age structured
  groups, see output of
  [`rsim.stanzas()`](https://noaa-edab.github.io/Rpath/reference/rsim.stanzas.md)

## Examples

``` r
# Read in Rpath parameter file and generate model object
Rpath <- rpath(AB.params)
# Create a 50 yr Rsim scenario
Rsim.scenario <- rsim.scenario(Rpath, AB.params, years = 1:50)
```
